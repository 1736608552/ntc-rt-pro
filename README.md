# NTC R-T Pro — 精密热敏电阻特性曲线分析仪

一款专为电子硬件工程师与 NTC 热敏电阻研发/质检人员设计的 Android 原生专业分析软件，采用**精密实验室深色仪器视觉风格（Obsidian Dark Lab）**，支持完全自主参数输入、高精度 R-T 曲线绘制、公差包络分析、双向反推、串联分压仿真、多格式导出与多 CDN 在线更新。

---

## 🎯 核心功能

1. **纯自主参数输入 & 精密 R-T 特性曲线**
   - 曲线页顶部直接输入 `R25 (Ω)`、`B 值 (K)`、`公差 (±%)`、`起始/终止温度`、`步进 (℃)`，修改即时重绘并自动本地记忆。
   - **线性坐标 / 对数坐标 (Log-Y)** 一键切换，清晰呈现宽温区阻值指数衰减。
   - **公差带包络填充**：支持固定 $R_{25}$ 偏差模式与叠加 $B$ 值公差传播模式。
   - **双曲线叠加对比**：实时对比不同 $B$ 值器件差异。
   - **触摸十字准星 + HUD 实时读数**：滑动指尖即刻查看 $T$、$R_{\text{nom}}$、$R_{\min}\sim R_{\max}$、灵敏度系数 $\alpha = -B / T^2$。
   - **高清工程图导出**：一键渲染 `1600×1000` PNG 曲线报告图。

2. **全量特性数据表与导出中心**
   - 温度检索跳转，点击任意行自动定位曲线游标。
   - 一键导出 **UTF-8 BOM CSV**、**Markdown 表格**，或生成 **嵌入式 C 语言查表数组 (LUT)**。

3. **工程反推与硬件分压仿真**
   - **阻值 ↔ 温度双向精算**（附带公差温度误差区间）。
   - **实测两点法反算 B 值**，并支持一键应用到主曲线。
   - **串联分压 & ADC 曲线仿真**：输入 $V_{CC}$、$R_{\text{ref}}$、ADC 位数，绘制 $V_{\text{out}}(T)$ 曲线并读取对应 ADC 码值。

4. **多 CDN 加速在线更新 & 正式签名**
   - 内置 `ghfast.top`、`gh-proxy.com`、`mirror.ghproxy.com`、`ghproxy.net`、`gh.llkk.cc` 与官方直连 6 路并发测速优选，失败自动顺位降级切换。
   - 采用独立 RSA-2048 Release Keystore 签名构建，支持 App 内一键下载并覆盖安装。

## 🚀 自动编译与下载

本项目配置了 GitHub Actions CI/CD 工作流（[`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)）：
- 每次推送至 `main` 分支自动执行单元测试 `./gradlew test` 与正式签名构建 `./gradlew assembleRelease`。
- 编译产出的 APK 与 `version.json` 自动发布至本仓库 [Releases](../../releases) 页面。
