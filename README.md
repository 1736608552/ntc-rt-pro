# NTC R-T Pro — 精密热敏电阻特性曲线分析仪

一款专为电子硬件工程师与 NTC 热敏电阻研发/质检人员设计的 Android 原生专业分析软件，采用**精密实验室深色仪器视觉风格（Obsidian Dark Lab）**，支持精确的 R-T 曲线绘制、公差包络分析、双向反推、串联分压仿真以及多格式工程报表导出。

---

## 🎯 核心功能

1. **精密 R-T 特性曲线工作台**
   - 默认内置 **南京时恒电子科技有限公司 5Ω / B4100 (±17%)** 特性模型（20.0℃ ～ 36.5℃，步进 0.5℃），同时预置宽温区及常见 10kΩ / 50kΩ / 100kΩ B3950/B3977 规格。
   - **线性坐标 / 对数坐标 (Log-Y)** 一键切换，清晰呈现宽温区阻值指数衰减。
   - **公差带包络填充**：支持固定 $R_{25}$ 偏差模式与叠加 $B$ 值公差传播模式。
   - **双曲线叠加对比**：实时对比不同 $B$ 值器件差异。
   - **触摸十字准星 + HUD 实时读数**：滑动指尖即刻查看 $T$、$R_{\text{nom}}$、$R_{\min}\sim R_{\max}$、灵敏度系数 $\alpha = -B / T^2$。
   - **高清工程图导出**：一键渲染 `1600×1000` 带完整规格参数与图例的 PNG 曲线报告图。

2. **全量特性数据表与导出中心**
   - 温度检索跳转，点击任意行自动定位曲线游标。
   - 一键导出 **UTF-8 BOM CSV**、**Markdown 表格**，或生成 **嵌入式 C 语言查表数组 (LUT)**。

3. **工程反推与硬件分压仿真**
   - **阻值 ↔ 温度双向精算**（附带公差温度误差区间）。
   - **两点实测法反算 B 值**，并支持一键应用到主曲线。
   - **串联分压 & ADC 曲线仿真**：输入 $V_{CC}$、$R_{\text{ref}}$、ADC 位数，绘制 $V_{\text{out}}(T)$ 曲线并读取任意温度下输出电压与 ADC 码值。

---

## 🧮 核心物理模型

$$R(T) = R_{25} \times \exp\left(B \times \left(\frac{1}{T + 273.15} - \frac{1}{298.15}\right)\right)$$

$$\alpha(T) = -\frac{B}{(T + 273.15)^2} \times 100\% \quad (\%/^\circ\text{C})$$
